Neighborhood Action Dashboard · módulo SERS · Diadema (SP) — cenário de estudo

VÃO

Uma passarela acesa sem ninguém é um vão de energia. O painel mede quanto de luz a cidade gasta em vão — e quanto dá para devolver.

SIMULADO protótipo de software · sem integração física

Uma noite na passarela-tipo

Potência de iluminação (kW) por hora, 18h–05h. Perfil de presença simulado; premissas em dados/premissas.csv.

Simulador

Fator de emissão: 0,0385 kgCO₂/kWh (MCTI, SIN média 2023). Irradiação: 4,0 kWh/m²·dia, PR 0,75.

Corredor de passarelas

Cada nó é uma passarela com fluxo de pedestres próprio (simulado). Brilho = nível de luz na hora escolhida; barra = potência.

Comparação dos cenários

Degrau solar: vale a pena agora?

Origem dos dados

FONTE fator de emissão (MCTI), irradiação horizontal de São Paulo (CBENS), fórmula E = P×t/1000.

HIPÓTESE potências, quantidades, tarifa, custos unitários, vida útil.

SIMULADO perfil de presença e a variação entre passarelas.

Resultados são projeções condicionadas às premissas, não medições.

Arquitetura

flowchart LR
 SOL[Módulos FV 1,65 kWp] --> INV[Inversor on-grid]
 REDE[Rede Enel SP] --> QD[Quadro da passarela]
 INV --> QD
 QD --> LUM[20 luminárias LED dimerizáveis]
 QD --> CAM[2 câmeras + gateway]
 RAD[Sensores de presença] --> CTRL[Controlador local]
 MED[Medidor kWh por circuito] --> CTRL
 CTRL -->|dimerização 30–100 %| LUM
 CTRL -->|MQTT| API[API + banco]
 API --> IND[Indicadores I1–I5]
 IND --> DASH[Neighborhood Action Dashboard]

Na entrega acadêmica, sensores e medidores são simulados por gerador de dados (código em calculos/). Nenhum hardware foi construído.
