# VÃO — Eficiência Energética em Passarelas

> Uma passarela acesa sem ninguém é um vão de energia.

Projeto desenvolvido para a **Global Solution 2026 — FIAP**, com foco em sustentabilidade urbana e eficiência energética por meio de iluminação inteligente em passarelas.

## 🌐 Acesse o projeto

**[→ Visualizar Dashboard Interativo](https://thvdora.github.io/vao/)**

## 💡 Sobre o projeto

O VÃO propõe uma alternativa para reduzir o desperdício energético na iluminação de passarelas, combinando iluminação LED adaptativa, sensores de presença e geração de energia solar.

O dashboard permite simular cenários e comparar seus impactos energéticos, ambientais e financeiros.

## 🎥 Acesse o vídeo-apresentação
**[→ Visualizar apresentação](https://vao-gs-2026.lovable.app/)**

## ⚙️ Funcionalidades

- Comparação de quatro cenários de iluminação.
- Simulação de consumo e economia energética.
- Indicadores de custos e emissões de CO₂.
- Ajuste de tarifas, quantidade de passarelas e custos solares.
- Análise de viabilidade financeira.
